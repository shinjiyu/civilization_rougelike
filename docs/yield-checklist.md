# Yield 系统设计检查清单

## 核心原则：每种 Yield 必须有不可替代的独占功能

防止"万物皆可换金币"的关键：如果 A 能做的事 B 也能做，那 A 和 B 就是同一个资源。

## 两类 Yield 的本质区别

```
投资型（引擎燃料）          得分型（分数引擎）
┌─────────────────┐       ┌─────────────────┐
│ 🪙 金币           │       │ 🔬 科技           │
│ 🌾 食物           │       │ 🎭 文化           │
│ ⚙️ 生产力         │       │ ⛪ 信仰           │
├─────────────────┤       ├─────────────────┤
│ 花掉才有用        │       │ 累积即计分        │
│ 不计入终分        │       │ 同时有独占花费渠道  │
│ 用于构建引擎      │       │ 既是分数也是能力    │
└─────────────────┘       └─────────────────┘

两类之间不可直接互换 ← 这是策略深度的来源
```

## 独占功能映射表

| Yield | 独占门(只有它能做) | 如果不投入会怎样 |
|-------|------------------|----------------|
| 🪙 金币 | 购买商店卡牌 | 无法获取新地块，引擎停滞 |
| 🌾 食物 | 解锁Ring-2棋盘格 | 只能用7格，空间极度受限 |
| ⚙️ 生产力 | 升级改良设施等级 | 改良永远Lv1，产出天花板低 |
| 🔬 科技 | (V2)解锁高级卡牌入池 | 商店永远只卖基础款 |
| 🎭 文化 | (V2)解锁政策卡buff | 没有任何全局被动加成 |
| ⛪ 信仰 | (V2)召唤伟人 | 没有爆发性手段 |

## 新内容添加检查清单

每次添加新的 Yield 使用渠道或新的游戏内容时，必须通过以下检查：

### ✅ 检查项

- [ ] **独占性**: 该 Yield 是否有至少1个"独占门"（只有它能做的事）？
- [ ] **不可互换**: 该 Yield 能否直接换成另一种 Yield？
  - 如果能：汇率是否足够差，使得"专精"优于"换汇"？
- [ ] **无功能重叠**: 是否存在两个 Yield 功能完全重叠？
- [ ] **必要性**: 投入该 Yield 为0时，游戏是否仍可通关？
  - 如果能：说明它不是必需的，需要加强独占功能
- [ ] **终分不可替代**: 终局得分中，该 Yield 的贡献是否不可替代？

### ❌ 常见反模式

1. **万能兑换所**: 任何 Yield 都能按汇率换成金币 → 所有 Yield 本质相同
2. **功能重叠**: 科技和文化都只是"纯得分" → 两者无区别，应各加独占功能
3. **可跳过资源**: 某个 Yield 完全不投入也能通关 → 该 Yield 无存在价值
4. **单一最优解**: 只堆某个 Yield 就能轻松获胜 → 其他 Yield 沦为摆设

## 系统关系全景图

```
┌─ 商店(随机地块) ←──── 🪙金币(购买) ←─── 市场/商业改良产出
│                  ←──── 🔬科技(V2:解锁新选项进池)
│
├─ 棋盘(放置空间) ←──── 🌾食物(人口→新格子)
│
├─ 地块升级       ←──── ⚙️产能(改良升级Lv1→2→3)
│
├─ 政策系统(V2)   ←──── 🎭文化(解锁政策槽+政策卡)
│
├─ 伟人系统(V2)   ←──── ⛪信仰(召唤伟人)
│
└─ 终局得分 = f(累积🔬, 累积🎭, 累积⛪)
                 ↑不含金币/食物/产能——它们是"过程资源"不是"结果"
```

## 张力设计

核心张力：**建引擎 vs 刷分数**

- 堆金币/食物/产能 → 引擎强，但分低
- 堆科技/文化/信仰 → 分高，但引擎弱、扩张慢
- 玩家必须找到平衡点 ← 这就是策略深度的来源

次要张力：**横向扩张 vs 纵向深化**

- 投资食物(解锁更多格子) + 金币(买更多牌) → 地块多但每块弱
- 投资产能(升级已有地块) → 地块少但每块强
- 最优解随局面动态变化
