# 游戏规则详细文档

## 一、游戏概述

**文明精铺 Roguelike** 是一款回合制地块策略游戏。玩家在 20 回合内，通过从随机商店购买地块卡牌、放置到六角棋盘、主动建造改良/区域、分配工人，利用邻接加成最大化科技/文化/信仰得分。

---

## 二、Yield 产出体系

### 6种 Yield

| Yield | 图标 | 角色 | 是否计入终分 |
|-------|------|------|------------|
| 金币 Gold | 🪙 | 商店购买地块卡牌、刷新商店 | ❌ 过程资源 |
| 食物 Food | 🌾 | 驱动人口增长 | ❌ 过程资源 |
| 生产力 Production | ⚙️ | 建造改良(8⚙️)/区域(15⚙️)/升级(10⚙️) | ❌ 过程资源 |
| 科技 Science | 🔬 | 升级商店等级（可花费），剩余计入得分 | ✅ 剩余计分 |
| 文化 Culture | 🎭 | 累积得分 | ✅ |
| 信仰 Faith | 🙏 | 累积得分 | ✅ |

### 终局得分

```
最终得分 = 剩余科技 + 累积文化 + 累积信仰
```

> 科技是"投资vs得分"的张力来源：花科技升级商店可获得更好地块，但会减少最终得分。

## 三、人口系统

### 核心规则

- **人口 = 可分配的工人数量**
- 城市中心**不占人口**，始终工作，始终产出
- 每 1 人口 = 可在 1 个非城市中心地块上安排工人
- **只有安排了工人的地块才会产出 yield**
- 初始人口：1（即除主城外可开采 1 块地）

### 食物与人口增长

| 参数 | 值 |
|------|---|
| 每人口每回合消耗食物 | 2 |
| 人口增长所需食物 | 8（累积净食物） |

**每回合食物计算：**

```
总食物产出 = 所有工作中地块的食物产出之和
食物消耗 = 当前人口 × 2
净食物 = 总食物产出 - 食物消耗
食物进度 += 净食物
```

**增长规则：**
- 当 `食物进度 ≥ 8` 时：人口 +1，食物进度 -8
- 新增人口自动分配到产出最高的空闲地块

**饥荒规则：**
- 当 `食物进度 < 0` 且 `人口 > 1` 时：人口 -1，食物进度重置为 0
- 自动撤回产出最低的工作地块的工人
- 人口最低为 1，不会降到 0

### 工人调配交互

- **点击地块**：选中该地块，信息面板显示详情和操作按钮
- **分配工人按钮**：为空闲地块分配工人
- **撤回工人按钮**：将工人从地块撤回
- **放置新地形卡后**：若有空闲工人，自动分配

### 初始状态示例

```
人口: 1
城市中心: 产出 2🪙 2🌾 1⚙️（免费，不占人口）
空闲工人: 1（可分配到第一块放置的地形上）

食物平衡: 总产出 2🌾 - 消耗 2🌾(1人口×2) = 净 0
→ 不投资食物源就无法增长人口
```

## 四、棋盘与地块系统

### 棋盘结构

2 环六角格棋盘，共 19 个格子：

| 区域 | 格子数 | 初始状态 |
|------|--------|---------|
| Ring-0（中心） | 1 | 城市中心，始终工作 |
| Ring-1（内环） | 6 | 已解锁，可放置地形 |
| Ring-2（外环） | 12 | 锁定，需人口解锁 |

### 地块解锁机制

Ring-2 格子的解锁与**人口增长**绑定：

```
可解锁的 Ring-2 格子数 = max(0, 当前人口 - 1)
```

| 人口 | 解锁的 Ring-2 格数 | 总可用格数 |
|------|-------------------|----------|
| 1 | 0 | 7（中心 + Ring-1） |
| 2 | 1 | 8 |
| 3 | 2 | 9 |
| ... | ... | ... |
| 13 | 12（全部） | 19 |

**解锁优先级**：优先解锁与已放置地形相邻的 Ring-2 格子。

### 地块四层结构

每个格子由 4 层叠加：

```
Layer 4: 区域(District)       ← 玩家主动建造，消耗生产力，与改良互斥
Layer 3: 改良设施(Improvement)  ← 玩家主动建造，消耗生产力，与区域互斥
Layer 2: 资源(Resource)        ← 地形卡自带，不可更改
Layer 1: 地形+地貌(Terrain+Feature) ← 地形卡自带，不可更改
```

**产出计算（仅工作中的地块）：**

```
地块产出 = 地形基础产出
         + 地貌修正
         + 资源加成
         + 改良产出 + 改良升级加成
         + 区域产出
         + 邻接加成
```

## 六、改良设施

通过消耗生产力(8⚙️)在有地形的格子上建造。可升级（10⚙️/级，最高3级）。

| 改良 | 产出 | 建造费 | 放置条件 | 邻接规则 |
|------|------|-------|---------|---------|
| 农场 🌾 | +2🌾 | 8⚙️ | 平地+可建 | 每相邻农场 +1🌾 |
| 矿山 ⛏️ | +2⚙️ | 8⚙️ | 丘陵+可建 | 每2相邻矿山 +1⚙️ |
| 商站 🏪 | +3🪙 | 8⚙️ | 可建 | 每相邻区域 +1🪙 |
| 伐木场 🪓 | +2⚙️ | 8⚙️ | 森林+可建 | 无 |
| 种植园 🌿 | +1🪙 +1🌾 | 8⚙️ | 平地+可建 | 若有相邻奢侈资源 +1🪙 |

**升级机制：** 每级在主要 yield 上 +1。例如农场 Lv2 = +3🌾，Lv3 = +4🌾。

## 七、区域

## 八、邻接加成系统

三种计算模式：

| 模式 | 计算方式 | 示例 |
|------|---------|------|
| `per_each` | 每匹配 1 个邻居 → +bonus | 学院：每山脉+1🔬 |
| `per_two` | 每匹配 2 个邻居 → +bonus | 学院：每2植被+1🔬 |
| `flat_if_any` | 只要有 ≥1 个匹配 → +bonus（不叠加） | 商业中心：若邻水域+2🪙 |

**匹配基于 Tag 系统**：每个地形/地貌/资源/改良/区域都有 tag 列表，邻接规则通过 tag 匹配。

## 九、商店系统

### 核心变化

**商店只出售地块卡牌**，不出售改良和区域。改良和区域通过消耗生产力主动建造。

### 地块等级

| 等级 | 标志 | 描述 | 示例 |
|------|------|------|------|
| ★ 普通(T1) | 1星 | 基础地形，无地貌无资源 | 草地、平原、沙漠、冻土 |
| ★★ 加成(T2) | 2星 | 带地貌或加成资源 | 草地丘陵、森林、山脉、湖泊、小麦草地 |
| ★★★ 稀有(T3) | 3星 | 带奢侈或知识资源 | 宝石丘陵、丝绸平原、远古遗迹 |

### 商店等级

玩家可消耗科技值升级商店等级，提高高等级地块出现概率。

| 商店等级 | 普通(T1) | 加成(T2) | 稀有(T3) | 升级费用 |
|---------|---------|---------|---------|---------|
| Lv.1 | 70% | 25% | 5% | - |
| Lv.2 | 40% | 45% | 15% | 15🔬 |
| Lv.3 | 15% | 45% | 40% | 30🔬 |
| Lv.4 | 5% | 30% | 65% | 60🔬 |

### 每回合刷新

每回合自动刷新 4 张地块卡牌（根据商店等级概率抽取）。

### 操作

| 操作 | 花费 | 效果 |
|------|------|------|
| 购买地块 | 卡牌标价🪙 | 获得地块卡牌，选择空位放置 |
| 刷新商店 | 2🪙 | 重新随机 4 张卡牌 |
| 升级商店 | 科技值 | 提高稀有地块出现概率 |
| 跳过 | 免费 | 不购买，直接结束回合 |

### 卡牌价格范围

| 卡牌等级 | 价格范围 | 说明 |
|---------|---------|------|
| ★ 普通 | 1-2🪙 | 基础地形 |
| ★★ 加成 | 3-4🪙 | 带地貌/加成资源 |
| ★★★ 稀有 | 4-6🪙 | 带奢侈/知识资源 |

## 十、建造系统

### 交互方式

1. 点击已有地形的地块 → 地块被选中
2. 信息面板显示可建造选项（根据地块Tag过滤）
3. 点击"建造"按钮 → 消耗生产力，建造改良/区域

### 建造规则

| 行为 | 费用 | 条件 |
|------|------|------|
| 建造改良 | 8⚙️ | 地块需满足改良的Tag要求，无已有区域 |
| 建造区域 | 15⚙️ | 地块需满足区域的Tag要求，替换已有改良 |
| 升级改良 | 10⚙️ | 已有改良且未达最高等级(Lv3) |

## 十一、回合流程

```
每回合执行顺序：

1. 产出结算
   - 计算所有【工作中】地块的 yield 总和
   - 金币 → 加入金库
   - 生产力 → 加入生产力储备
   - 科技 → 加入科技储备（可花费+计分）
   - 文化/信仰 → 累积计分
   - 食物 → 计算净食物（总产出 - 人口×2）→ 加入食物进度

2. 人口检查
   - 若食物进度 ≥ 8 → 人口+1，食物进度-8
     → 自动分配工人到最佳空闲地块
     → 检查是否解锁新的 Ring-2 格子
   - 若食物进度 < 0 且人口 > 1 → 人口-1，食物进度归0
     → 自动撤回最差地块的工人

3. 商店刷新
   - 根据商店等级，生成 4 张随机地块卡牌

4. 玩家行动（可做以下任意操作）
   - 购买地块卡牌 → 选择空位放置
   - 建造改良/区域 → 选中地块，点击建造按钮
   - 升级改良 → 选中地块，点击升级按钮
   - 升级商店等级（消耗科技）
   - 刷新商店（2🪙）
   - 调配工人（选中地块，点击分配/撤回按钮）
   - 结束回合

5. 回合结束 → 进入下一回合

20 回合后 → 游戏结束 → 显示最终得分
```

## 十三、策略要点

### 核心张力

1. **引擎 vs 得分**：投资金币/食物/产能建引擎，还是投资科技/文化/信仰直接得分？
2. **横向 vs 纵向**：食物扩人口拿更多地块，还是产能升级现有地块？
3. **科技：花费 vs 积攒**：花科技升级商店获得更好地块？还是保留科技作为终分？
4. **当前 vs 未来**：农场集群前期慢但后期食物爆发，区域集群前期贵但邻接收益高。

### 关键时机

- **回合 1-5**：建立食物基础，争取回合 5 前第一次人口增长
- **回合 3-7**：积攒生产力，建造第一个改良（矿山/农场）
- **回合 5-10**：考虑是否花科技升级商店，铺开区域核心（学院/圣地/剧院）
- **回合 10-15**：优化工人分配，升级关键改良，建邻接网络
- **回合 15-20**：最大化得分型 yield 产出
