# 文明精铺 Roguelike - 游戏设计文档

## 概述

一款 Roguelike 风格的地块精铺策略游戏。玩家通过从随机商店中购买地块卡牌，将其放置到自己的六角棋盘上，合理分配工人，利用邻接加成最大化产出，在 20 回合内追求最高得分。

## 核心理念

**有限资源下的效果最大化**，体现在三个约束维度：

| 约束维度 | 具体内容 |
|---------|---------|
| 空间约束 | 2环六角棋盘（19格），Ring-2需人口解锁 |
| 选项约束 | 每回合随机4张卡牌，选1张购买 |
| 时间约束 | 固定20回合，每回合1次购买行动 |
| 劳动力约束 | 人口=工人数，只有工作中的地块才产出 |

## Yield 体系（6种产出）

### 投资型（花掉才有用，不直接计分）

| Yield | 独占功能 |
|-------|---------|
| 🪙 金币 | 商店购买卡牌、刷新商店 |
| 🌾 食物 | 驱动人口增长（净食物累积达8→+1人口） |
| ⚙️ 生产力 | 升级已有改良设施(10⚙️/级，最高Lv3) |

### 得分型（累积即计分）

| Yield | 附加功能（V2规划） |
|-------|-----------------|
| 🔬 科技 | V2: 解锁高级卡牌入池 |
| 🎭 文化 | V2: 解锁政策卡buff |
| ⛪ 信仰 | V2: 召唤伟人 |

### 终局得分

```
最终得分 = 累积科技 + 累积文化 + 累积信仰
```

## 人口系统

- 人口 = 可分配工人数（城市中心免费不占人口）
- 食物消耗: 每人口 2🌾/回合
- 增长: 净食物累积达 8 → 人口+1
- 饥荒: 净食物持续为负 → 人口-1（最低1）
- 人口增长 → 自动解锁 Ring-2 格子（每多1人口解锁1格）

## V1 已实现

- 6种地形 + 5种地貌 + 7种资源
- 5种改良设施（可升级Lv1→3） + 5种区域
- 2环六角棋盘（19格）+ 人口驱动的解锁机制
- 人口系统：增长/饥荒/工人调配
- 商店系统：随机4卡/刷新/购买放置
- 邻接加成系统（per_each/per_two/flat_if_any）
- 纯H5单文件输出（dist/index.html）

## V2 规划

- 生产力机制重构：改良设施用生产力建造而非金币购买
- 科技树：科技值解锁更高级的卡牌进入商店池
- 政策系统：文化值解锁全局被动buff
- 伟人系统：信仰值召唤一次性强力效果
- 奇观：消耗大量生产力建造的唯一性超强建筑
- 多幕结构：每幕20回合，幕末有考核阈值
